# Start here, with any AI

You do not have to use a specific app to get value out of this folder. If you have an AI that can read and write files on your machine, you can point it at this file and it becomes your guide.

The best experience is [Claude Code](https://claude.com/claude-code), and here is the honest case for it. The terminal asks less of you than you think. You do not write code, you talk to it in plain English, and it does the actual work on your files, not just gives you advice you then have to go do. If you are on the fence, try it first. But if you would rather use something you already have, this works too. Read on.

## If you have Claude Code

Stop reading this file. Just open this folder in Claude Code and say hi, or run `/start`. The guide takes it from here and gets you a sorted day in about five minutes.

## If you are using something else

This works with any AI that can read and write files in a folder, for example the Claude desktop app, CoWork, or another file-capable assistant. Paste the block below to it, with this folder open or attached.

```
You are my guide for a folder called Remix Yourself. It holds five small tools that share one memory so they compound.

Do this, in order:
1. Read CLAUDE.md in this folder. It tells you who to be (speak plainly, first person, no em-dashes, no colons mid-sentence, no hype) and how the folder works.
2. Read LEARN-PATH.md. That is the order you teach me in.
3. Start me at step 1. Do not explain the whole system first. Get me a real result fast.
   Step 1 is the "today" tool. Ask me to dump everything on my plate today, messy is fine. Then write me a sorted today.md file in this folder, ordered by what actually matters, with a Focus line at the top. Before you create the file, tell me what you are about to do and that you will not touch anything I did not ask for.
4. After that win, offer me the next step from LEARN-PATH.md, one at a time. Do not front-load concepts.

The tool recipes live in the .claude/commands/ folder (today.md, capture.md, draft.md, process-transcript.md, prep.md, research.md). Read the matching one before you run that step. Keep my files, never rewrite what I wrote, always add on top and date it.
```

That is the same path a Claude Code user gets, run by hand. You lose the slash commands and the automatic session memory, but you get the same five tools and the same order.

## What you get either way

A sorted day, a capture inbox, drafts in your voice, meetings that prep and file themselves, and a shared memory that makes each tool sharper as you use the others. Where it goes when you want more is in `LADDER.md`.
