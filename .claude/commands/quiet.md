# /quiet

The person wants the guide to stop talking. Respect it immediately.

## What to do

1. Set `guide: off` in `.remix/state.md` (create the file if it is missing). Leave the rest of the state intact so `/start` can resume later.
2. Say one line, no more:

> Guide is off. The tools still run, `/today`, `/capture`, `/draft`, `/process-transcript`, `/prep`, `/research`. Run `/start` when you want me back.

3. Stop. Do not offer next steps, do not teach, do not check in. Quiet means quiet.

## After this

While the guide is off, do not jump in as the guide when they open the folder or run a tool. Just run what they ask. `/start` is the only thing that turns the guide back on.
